Project Description
MediQuick is a Java-based healthcare management system designed to streamline appointment booking, patient records, and medical services.

Technologies Used
Java
Spring Boot
Maven
MySQL
REST API
Project Structure
controller – Handles API requests
service – Business logic
repository – Database operations
model – Entity classes
resources – Configuration files
Setup Instructions
Prerequisites
Java 17+
Maven
